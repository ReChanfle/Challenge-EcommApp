# CodeIgniter 4 Challenge EcommApp

## Installation & updates

Primero clonar el repo con el siguiente link :
https://github.com/ReChanfle/Challenge-EcommApp.git

Requisitos:
- Node
- PHP 8.2 o mayor
- Apache

## Setup

Una vez clonado el repo ejecutar el comando
`composer install` despues `npm run dev` ya que la app esta usando webpack para compilar el js
y por ultimo `php spark serve` para inicializar el servidor
